# Unpublished templates — not a release

Everything in this directory is documentation only.

The JSON files contain the extra top-level property `UNPUBLISHED_TEMPLATE_ONLY` and placeholder values. They deliberately fail the strict live schemas and must never be copied to `updates/stable/`, signed as-is, uploaded as release metadata, or interpreted by a launcher.

Production documents must be generated by the reviewed offline release builder, validated against the schemas, signed with an external NIST P-256 private key, independently verified, and published according to [the release gate](../../docs/PUBLISHING.md).
